Detailed Description

Configure interrupt (subscribe/unsubscribe, enable/disable, query subscribed interrupts, query enabled interrupts, etc.).

Note
This struct uses a constructor to properly initialize itself. Do not use memset or bzero to initialize or "clear" it.
